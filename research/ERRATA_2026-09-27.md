## 4. XSMOM multi-universe report: "term1 reliably present" and "demean collapses"

**Corrects** `research/xsmom/XSMOM_UNIVERSES_REPORT.md:31`, `:39-43` (the "demean test"
column) and `:47`, and `research/xsmom/XSMOM_UNIVERSES_README.md:160`.

These sentences were typed into the report generator, not computed from the results. The
study's own CIs (`research/xsmom/xsmom_universes_decomposition.csv`) say otherwise:

- **term1** (own-autocorrelation, the channel TSMOM harvests) has a CI that **contains 0 in
  5/5** universes, and so does **term2** (lead-lag). Only **term3** (static cross-sectional
  dispersion) excludes 0, in 5/5. The decomposition therefore cannot separate the terms:
  it shows neither a lead-lag channel nor that XSMOM's profit comes from the source TSMOM
  harvests.
- The "demean test" column was set to "collapses" whenever the demeaned CI crossed 0, which
  it did everywhere. Measured against the rank baseline (the report's own "Confound" lines
  `:67`, `:88`, `:109`, `:130`, `:153`):

| universe | rank baseline → demeaned Sharpe | demean test |
|---|---|---|
| U1 | +0.01 → +0.08 | no collapse |
| U2 | −0.14 → +0.03 | no collapse |
| U3 | +0.03 → +0.02 | no collapse |
| U4 | +0.31 → −0.07 | **collapses** |
| U5 (negative control) | +0.01 → +0.02 | no collapse |

  A collapse means a positive baseline that at least halves. Only U4 collapses. The
  pre-registered U5 negative control, predicted to "collapse hardest under demeaning"
  (`XSMOM_UNIVERSES_README.md:45`), did not.

`run_xsmom_universes.py` now derives these labels and sentences from the CIs and Sharpes
(`tests/test_xsmom_universes.py`). Re-run on the pinned price snapshot (`data/README.md`),
it reproduces every number in the committed report and CSVs and changes only the sentences
above. The committed report is kept as the dated run record. The verdict is unchanged:
`falsified`, 0/5 universes.
