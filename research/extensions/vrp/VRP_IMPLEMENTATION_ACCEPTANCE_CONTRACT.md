# TSMOM-VRP-01 — IMPLEMENTATION ACCEPTANCE CONTRACT (what S2 must satisfy before any real outcome can be revealed)

```
LINEAGE     = TSMOM-VRP-01
GOVERNS     = the S2 build of the VRP research package (its own package; never imports or modifies the C-A engine, pipeline or store)
BINDS TO    = VRP_PREREGISTRATION.md (sealed; hash in VRP_SEAL_MANIFEST.md)
RULE        = NO real Stage-A or Stage-B result may be GENERATED under a governed run, and NONE may be REVEALED, before every
              item below is PASS on the sealed text and on synthetic fixtures. Machine checks before model checks.
```

Every item is mechanical. Every item is evaluated on **synthetic fixtures or on identities that touch no return**, except where an item explicitly names the real acquired inputs (hashes, chain completeness), which reveal no outcome. The S2 session records each result in a tracked acceptance log with the commit at which it passed. An item that cannot be made to pass is a **VRP-VALIDITY** failure (Class 1) unless it is one of the two implementability items marked below (Class 2).
